# 📊 Gabriel Orlandi Portes | Portfólio Pessoal

**🔗 Acesse o site:** [gabriel-orlandi-portes.github.io](https://gabriel-orlandi-portes.github.io/)

Portfólio pessoal desenvolvido para apresentar minha trajetória, projetos, habilidades e experiências na área de **dados**.

---

## 📋 Sobre o projeto

Este portfólio centraliza minhas principais informações profissionais: experiência, formação acadêmica, stack técnica e projetos desenvolvidos com Python, SQL e Power BI, construído com foco em:

- Identidade visual própria.
- Responsividade.
- Projetos apresentados com contexto real (tecnologias usadas, objetivo e link para o código).
- Apresentação direta, sem enrolação, pensada para recrutadores e empresas.

## ✨ Funcionalidades

- Design responsivo (desktop, tablet e mobile)
- Menu de navegação com scroll suave entre seções
- Animações de entrada ao rolar a página (scroll reveal)
- Cards de projetos com tags de tecnologias e links diretos para os repositórios
- Grade de tecnologias com tooltip ao passar o mouse

## 🛠️ Tecnologias utilizadas

| Tecnologia | Uso |
|---|---|
| HTML5 | Estrutura semântica das páginas |
| CSS3 | Estilização, grid, flexbox e responsividade |
| JavaScript | Efeito de digitação, menu mobile e scroll reveal |
| Google Fonts | Space Grotesk, Inter e JetBrains Mono |
| Simple Icons | Ícones das tecnologias e redes sociais |
